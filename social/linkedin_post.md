# 🚀 Open Source Release: Graph Database Cloud Benchmark

I'm excited to share my latest open-source project: **Graph Database Cloud Benchmark**.

This project provides a reproducible framework for benchmarking multiple graph database platforms under the same workload, making performance comparisons more transparent and easier to validate.

### Key Features

- 📊 Automated benchmarking
- 🔄 Reproducible methodology
- 🗂️ Synthetic dataset generator
- ⚡ Multiple graph database support
- 📈 Automatic chart generation
- 🐳 Docker-based local environment
- 🤖 GitHub Actions CI workflow
- 📄 CSV and JSON result export

### Benchmark Workloads

- Direct neighbor lookup
- Friends-of-friends traversal
- Recommendation queries
- Shortest-path search
- Aggregation queries

### Metrics Collected

- Average latency
- Median latency
- P95 latency
- P99 latency
- Throughput (QPS)
- Peak memory usage
- Peak CPU utilization

The repository is designed to be easy to reproduce, extend, and adapt for additional graph database platforms.

Contributions, feedback, and suggestions are always welcome!
